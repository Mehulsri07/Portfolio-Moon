TypeScript Released — auto-updating

StrataField

Installer cut from 134 MB to 3.5 MB · in daily use at a drilling business

Offline-first Windows desktop app used day to day by my family's drilling business to record borewells, soil layers, pipes, water levels and site photos — with an offline city map of water depths and geological cross-sections.

Implementation

Rebuilt the original Electron version on Tauri 2, cutting the installer from 134 MB to 3.5 MB, and replaced sql.js with native SQLite (schema migrations, edit history, recycle bin, daily backups) that imports the old app's data automatically. GitHub Actions runs typecheck, lint, unit tests, a Windows end-to-end test and a clean-machine installer test; tagged releases publish signed builds that installed copies auto-update from.

Tech Stack

Tauri 2, React, TypeScript, Rust, SQLite, Leaflet, Vitest, GitHub Actions

Go AWS EC2

LoadLab

Go behind Nginx on EC2 · Prometheus and Grafana · three k6 load profiles

A load-testing and observability sandbox built to fail on purpose: Nginx in front of a Go backend with deliberately CPU- and memory-heavy routes, scraped by Prometheus and visualised in Grafana.

Implementation

Deployed as a Docker Compose stack on EC2, with the backend rewritten from Node.js to Go. Low, medium and high k6 load profiles show where p95 latency climbs and which resource saturates first. Fixed a Grafana redirect loop behind the Nginx sub-path proxy by correcting the root URL and forwarded headers.

Tech Stack

Go, Nginx, Docker Compose, Prometheus, Node Exporter, Grafana, k6, AWS EC2
